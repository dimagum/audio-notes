# Кандидаты для расширения evaluation-наборов

Этот файл не является manifest и не определяет состав `notes_test`.
`notes_test_manifest.jsonl` — фиксированный набор для сопоставимой оценки.

## Статусы

- `candidate` — запись найдена, но ещё не проверена
- `reviewed` — аудио и транскрипт выборочно проверены
- `selected` — запись выбрана для нового набора
- `rejected` — запись сознательно исключена
- `deferred` — может пригодиться позже, но пока не используется
